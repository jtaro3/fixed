# デザインフォルダ

ゲームの見た目に関するデータをまとめるフォルダです。ゲームルールや敵の移動処理は含めません。

| ファイル | 内容 |
| --- | --- |
| `tokens.css` | 色、フォント、角丸など、画面全体で共通利用するデザイントークン |
| `styles.css` | レイアウト、ボタン、パネル、ゲーム画面、スマホ表示のスタイル |
| `theme.js` | Canvas内のコア・敵の発光色やグラデーションのテーマ定義 |

## 差し替え方法

- ページ全体の色やフォントは `tokens.css` を変更する。
- パネルやボタンの形・余白は `styles.css` を変更する。
- コア・敵を画像素材へ置き換える場合は、`theme.js` に画像ファイルの対応表を追加し、`game.js` がその対応表を読み込むようにする。

この構成により、ゲームルールを変更せずに見た目だけを差し替えやすくする。
