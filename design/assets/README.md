# 画像アセット

現在のコアと敵の見た目をSVG画像として保存しています。SVGは透明背景で、拡大しても画質が劣化しません。

| ファイル | 使用箇所 |
| --- | --- |
| `core.svg` | 画面中央のコア（○） |
| `enemy-hp1.svg` | 耐久1の敵（青） |
| `enemy-hp2.svg` | 耐久2の敵（緑） |
| `enemy-hp3.svg` | 耐久3の敵（黄） |
| `enemy-hp4.svg` | 耐久4の敵（赤） |
| `enemy-hp5.svg` | 耐久5の敵（灰） |

## 画像を差し替える場合

同じファイル名・同じ拡張子で置き換えれば、`game.js` を変更せずに差し替えられます。PNGやWebPを使う場合は、`design/theme.js` の該当パスだけを変更します。

- コア画像は正方形・透明背景を推奨。
- 敵画像は正方形・透明背景を推奨。
- 敵は耐久1〜5の状態ごとに別画像を用意する。
