# CORE DEFENSE

中央で固定されたコア（○）へ向かう敵（×）を、タップして破壊するブラウザゲームです。

## 遊び方

1. 難易度を選び、「ゲームを開始」を押す。
2. 敵はコアと重ならない離れた場所から出現し、自動でコアへ近づく。
3. 敵をクリック／タップして破壊する。
4. 敵がコアに触れるとゲーム終了。

## 調整できる設定

`game.js` の `DIFFICULTIES` で、難易度ごとに以下を変更できます。

- `maxEnemies`: 同時に画面上へ出現できる敵の最大数（標準は5体）
- `spawnEvery`: 敵の出現間隔（標準は5秒）
- `speed`: 敵がコアへ向かう速度

`index.html` をブラウザで開くだけで遊べます。
