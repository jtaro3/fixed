# CORE DEFENSE

中央で固定されたコア（○）へ向かう敵（×）を、タップして破壊するブラウザゲームです。現在のバージョンは **v1.2.3** です。

## 遊び方

1. 難易度を選び、「ゲームを開始」を押す。
2. ゲーム開始直後に敵が1体出現し、その後は2秒ごとに、コアと重ならない離れた場所から自動で出現する。
3. 敵をクリック／タップすると耐久が1減る。耐久は1〜5で、青・緑・黄・赤・灰の順に表示される。
4. 敵がコアに触れるとゲーム終了。
5. ゲーム中は開始ボタンと同じ位置の「一時停止」で止められる。もう一度押すと再開。
6. ゲーム中は、タップ操作が乱れないようスマホのズームを無効化する。

## 調整できる設定

`game.js` の `DIFFICULTIES` で、難易度ごとに以下を変更できます。

- `maxEnemies`: 同時に画面上へ出現できる敵の最大数（標準は5体）
- `spawnEvery`: 敵の出現間隔（標準は2秒）
- `speed`: 敵がコアへ向かう速度

`index.html` をブラウザで開くだけで遊べます。
